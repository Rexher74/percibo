# Percibo

Juego web de retos de percepción: cada día, cinco pruebas elegidas entre veinte. Dos minutos, una puntuación.

**Jugar:** https://rexher74.github.io/percibo/

## Los 20 retos

| | Reto | Qué mide |
|---|---|---|
| 🎨 | Color | Recrear de memoria un color visto 2 s |
| 📏 | Longitud | Reproducir una longitud en otra orientación |
| ⭕ | Centro | Encontrar el centro de un arco |
| ⏱️ | Duración | Reproducir un intervalo de tiempo |
| 🎵 | Nota | Igualar una nota musical (necesita sonido) |
| 🟠 | Área | Igualar el área de dos figuras distintas |
| ⚖️ | Equilibrio | Señalar el centro de masas de un polígono |
| 🌗 | Gris | Igualar grises sobre fondos que engañan |
| 🚇 | Túnel | Predecir cuándo sale una bola oculta |
| 🥧 | Porción | Estimar el porcentaje de un gráfico circular |
| 👁️ | Cambio | Ceguera al cambio con parpadeo |
| 🔍 | Matiz | Encontrar la casilla de color distinto |
| ⚡ | Reflejos | Tiempo de reacción |
| 🔄 | Rotación | Rotación mental: ¿igual o espejo? |
| 📍 | Posición | Memoria espacial de un punto fugaz |
| 🫧 | Mayoría | Comparar cantidades de un vistazo |
| 🌪️ | Flujo | Dirección de movimiento coherente |
| 🔲 | Cuadrado | Convertir un rectángulo inclinado en cuadrado |
| 🏹 | Flechas | Ilusión de Müller-Lyer |
| 🧱 | Oculta | Ilusión de Poggendorff |

## Uso local

HTML, CSS y JavaScript sin dependencias. Abre `index.html` o sirve la carpeta:

```bash
python3 -m http.server 5173
```
